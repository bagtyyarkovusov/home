# Home

Personal wiki and starting point for project planning, research, and work that spans repositories. In T3 Code, open **Home** for those sessions. Start implementation in the target T3 project with its own worktree.

- [Projects](projects/README.md) — public project pointers
- [Shared workflow](docs/workflow.md) — shaping, shipping, and where to save what you learn
- [Requirements and diagrams](docs/requirements-and-diagrams.md) — planning an MVP around scenarios and acceptance checks
- [Glossary](GLOSSARY.md) — terms used across the wiki
- [AGENTS.md](AGENTS.md) — how to route and hand off a session

Inspired by [The Home Repo Pattern](https://www.aihero.dev/the-home-repo-pattern).

Keep private project pointers and personal references in the ignored `.local/` directory. Use `.local/README.md` as its index.
