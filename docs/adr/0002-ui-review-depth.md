# Match UI review depth to the design decision

Accepted 2026-11-25.

Use direct acceptance checks for routine UI work. Choose independent review when its findings can change a product decision or sign-off. Use a numeric rubric at the user's request or at an agreed scored checkpoint. Projects can name those checkpoints alongside their existing acceptance criteria.

The previous blanket rule put a Penpot navigation index through the same scored review loop as payment approval. The index needed a link and discoverability check. Payment approval benefits from independent evidence about what the customer can see, authorize and recover. The [design and prototyping guide](../design-and-prototyping.md#choose-the-review-depth) gives each kind of work proof that fits its impact.
